# 🧪 Interactive Periodic Table

A modern, responsive, and interactive Periodic Table web application built using pure **HTML5, CSS3, and JavaScript**.

## ✨ Features
- **Complete Dataset:** Contains all 118 elements with accurate placement.
- **Category Filtering:** Filter elements by group (Noble Gases, Metals, Non-metals, etc.).
- **Interactive Details Modal:** Click on any element to view detailed information (Atomic mass, group, period, phase).
- **Responsive & Modern Design:** Styled with CSS Grid, Flexbox, and dark-mode aesthetic.

## 🛠️ Technologies Used
- **HTML5:** Semantic layout structure.
- **CSS3:** Custom CSS Grid layout, smooth hover transitions, and dark UI theme.
- **JavaScript (ES6):** Dynamic DOM manipulation, filtering logic, and interactive modal dialog.
